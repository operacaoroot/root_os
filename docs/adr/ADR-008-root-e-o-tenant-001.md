# ADR-008 · A ROOT é o tenant 001

- **Data:** 20/08/2026
- **Situação:** aceita
- **Origem:** transcrita de `Obsidian/Root/20-empresa/root-os/HANDOFF-DEV/03-ARQUITETURA.md`
  (versão 1.0 · 20/08/2026), seção "6. Registros de decisão". O vault é somente leitura;
  esta cópia no repositório existe para que a decisão viaje junto com o código.

## Contexto

Toda quebra dói primeiro em casa.

## Decisão

O `Org` atual do `marketing-os` vira o primeiro tenant e é o primeiro a migrar em cada fase.

## Consequências

Além do risco bem distribuído, isso resolve uma peça do material comercial: a ROOT operando sobre o
próprio sistema é a prova que sustenta o preço de tudo o que vem depois.
