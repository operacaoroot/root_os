# DEMO — Condições financeiras

Exemplo fictício de despesa mensal de BRL 100.00, sem dados bancários, documentos ou contato reais. A conta é uma caixa de demonstração com saldo inicial zero; a contraparte é DEMO — Fornecedor fictício.

O contrato serve à prévia F08. Gerar uma inscrição, registrar uma decisão e pagar são etapas diferentes. Este pacote prepara somente os cadastros e o contrato elegível. Não gera obrigação nem registra decisão automaticamente.
