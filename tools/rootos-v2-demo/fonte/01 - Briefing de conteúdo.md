# DEMO — Briefing de conteúdo

Produzir um texto curto explicando como uma pessoa encontra a versão de uma fonte antes de criar uma tarefa. Público fictício: equipe de uma empresa de demonstração. A entrega é um rascunho interno, sem postagem externa.

Critérios: mencionar origem e versão escolhidas; conservar a citação usada pela tarefa; separar aprovação da criação do material. O texto não deve atribuir ao ROOT OS resultados que este exemplo não comprovou.
